# QRDine Context

QRDine is a multi-tenant SaaS platform for cafes and restaurants.

Architecture:
- React + Vite + Tailwind
- Node.js + Express
- MongoDB Atlas
- Socket.IO
- JWT Authentication

Core Models:
- Cafe
- User
- Category
- MenuItem
- Table
- Order
- WaiterRequest

Requirements:
- Production-ready code
- Scalable folder structure
- Multi-tenant architecture
- Every business entity belongs to a cafeId
- Use modern JavaScript
- Use async/await
- Use proper error handling
- Use MVC architecture
